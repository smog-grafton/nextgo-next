# Horan reference audit

Date researched: 14 November 2026. Reference: `https://www.horan.tech/`.

## Design boundary

The reference informed the interaction pattern only: a dark, spacious layout; centered glass-like desktop navigation; compact navigation on scroll; broad mega menus; large typography; card-led content; and responsive mobile navigation. The implementation does not copy Horan branding, imagery, clients, addresses, written content or logos.

## Next Go Tech Africa implementation

| Area | Implementation |
| --- | --- |
| Header | Fixed floating navigation with scroll compaction, accessible mega menus and a mobile drawer |
| Hero | Next Go Tech Africa positioning with custom product artwork and a Products CTA |
| Motion | Reveal transitions, subtle hover movement and reduced-motion support |
| Content | Verified MySQL content for products, services, solutions, values and company messaging |
| Enquiries | Laravel lead-submission endpoint rather than a browser-only form state |
| Responsive layout | Fluid typography and single-column layouts for narrow screens |

The visual treatment is an original Next Go Tech Africa implementation built around the requested reference interaction language.
