# Next Go Tech design system

## Tokens

| Token | Value | Use |
| --- | --- | --- |
| Background | `#090909` | Main canvas |
| Surface | `#17191D` | Elevated sections/cards |
| Surface 2 | `#1E2127` | Form and higher-elevation surfaces |
| Text | `#F5F6FA` | Headings and actions |
| Muted | `#A0A3AD` | Supporting content |
| Border | `#292C33` | Hairline borders |
| Primary | `#0866FF` | CTA, icons, active states |
| Hover | `#1877F2` | Primary action hover |

## Shape and type

- Inter variable via `next/font` gives the large display letterforms and compact UI label rhythm.
- Heading tracking is intentionally tight (`-.065em` to `-.10em`).
- Buttons use fully rounded 999px capsules; panels use 18–35px rounded corners.
- Surfaces are low-contrast charcoal, with one bright blue focus colour.

## Visual language

Device/product scenes use an original generated hero image and CSS-built conceptual dashboards, maps, maps, charts, and data surfaces. They are not snapshots of the reference or any real client product.
